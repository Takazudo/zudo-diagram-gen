# Scenario recovery

- **One diagram:** ground exact facts and target/fonts; create one session and one candidate. Resolve a tone or explicit custom drawing conventions, validate, capture and actually open its PNG. Deliver the inspected saved drawing within the direct request, and present it for review without claiming user approval. Integrate only when authorized. Do not force a sweep or require a project style lock.
- **Five-session sweep:** create a project using createProject({project:true,sessions:[five explicit specs]}) from the public API when one default session is insufficient. Ground each brief/target independently. Assign each tone to one author across all five sessions; each candidate has one writer. Coordinator owns registrations/rounds/comparisons. Record missing entries if a worker fails, inspect surviving candidates and resume that worker within two correction rounds. Do not silently omit a requested session.
- **Review transfer:** download/copy review JSON from the actual viewer, save the explicit caller file, and resume --review. Confirm project/session-qualified identity, chosen ID, fingerprint and keep/change notes. Do not infer browser storage or claim source writes. A named user choice can be consumed directly; fixture choices remain tests.
- **Saved refinement and adoption:** read the named saved baseline and current fingerprint. Create r02 with a new child ID/parent; verify original bytes remain untouched, then edit only requested aspects and recapture/inspect. Ask for project-wide style intent only if needed for requested adoption. A palette/kit change creates a new immutable snapshot and explicit adopt; drawing choice alone grants no lock.
- **Missing browser:** report CAPTURE_UNAVAILABLE and exact consumer setup from commands.md. Keep created candidates and checks, mark visual verification pending, and resume after explicit capability setup. Never auto-install, use a fake screenshot, invent inspection, or substitute an improvised screenshot server.
- **Stale evidence:** change any saved SVG, effective style, placement, font/browser/DPR or image input and treat affected evidence separately as stale/unknown. Preserve notes and old selection; recheck, recapture and actually inspect affected images. Transfer renewed explicit review before claiming acceptance.

For every scenario record actual commands, envelopes/exits, saved IDs/lineage and files, evaluator image observations (only if actually opened), review source/purpose, exact exports and remaining blockers. Separate automated contract checks, actual visual evaluation, user approval and test decisions.
