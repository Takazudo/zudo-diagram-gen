# 空席と保留中の席

## Intent

架空の読書会の四席を、利用できる席とまだ選べない席が分かるように説明する。

## Must show

- 席は四つだけ。A席は予約済み、B席とC席は空席、D席は保留中。
- 選べる席はB席とC席だけ。
- 保留中のD席は選択不可。予約済みとも空席とも異なる。

## May drop

- 人名、残り時間、会場の実際の形。

## References

この説明はP00のために作成した架空の設定。外部資料・私有資料・第三者画像は使用していない。

## Lock

事実、状態、矢印の意味、下記ラベルを固定する。色は共通palette.jsonの意味役を使う。テスト用の描画であり、ユーザーによる選択・承認・プロジェクトスタイル固定ではない。

- `A席：予約済み`
- `B席：空席`
- `C席：空席`
- `D席：保留中`

## Target

360 × 240 CSS pixels。配置はplacement.json。レイアウトの課題はcompact。最終サイズで確認する。

## Language and fonts

日本語。Noto Sans CJK JPを優先しsans-serifを予備とする。実際に使われたフォントと代替・欠落グリフの不確実性を記録する。フォントそのものは配布していない。ラベルは改行可能、省略不可。
