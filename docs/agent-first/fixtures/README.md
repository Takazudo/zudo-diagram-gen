# Contract fixture scope

`contract-cases.json` supplies minimal planned-interface positives, complete negative JSON inputs and filesystem-context scenarios. Future owners run the same cases against runtime validation and published schemas. A positive project mapping uses a deliberately synthetic fingerprint and needs the corresponding session/candidate context; it is not a valid example session on disk. The scheme describes a fixture tone, not a new production tone or an approved pilot style. Copy resource paths into an isolated fixture package root before resource validation.

Public evaluation inputs live in `../evaluation/`; they contain ordinary session metadata, invented authoritative briefs, frame/slot placements, a bounded two-theme palette and factual checklists. No artwork/model output or visual approval is claimed by P00.
