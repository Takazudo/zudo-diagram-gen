# 返却場所への案内

## Intent

架空の道具貸出所で、返却時の分岐と空の返却箱を縦長の掲示で説明する。

## Must show

- 入口から返却確認台へ進む。
- 破損なしなら返却箱へ、破損ありなら相談窓口へ進む。
- 返却箱は現在空。空でも返却に使える。
- 相談窓口への分岐を警告役で示すが罰金や返却拒否を示さない。

## May drop

- 実在の地図、貸出番号、料金、建物写真。

## References

この説明はP00のために作成した架空の設定。外部資料・私有資料・第三者画像は使用していない。

## Lock

事実、状態、矢印の意味、下記ラベルを固定する。色は共通palette.jsonの意味役を使う。テスト用の描画であり、ユーザーによる選択・承認・プロジェクトスタイル固定ではない。

- `入口`
- `返却確認台`
- `破損なし`
- `返却箱：空`
- `破損あり`
- `相談窓口`

## Target

320 × 480 CSS pixels。配置はplacement.json。レイアウトの課題はportrait。最終サイズで確認する。

## Language and fonts

日本語。Noto Sans CJK JPを優先しsans-serifを予備とする。実際に使われたフォントと代替・欠落グリフの不確実性を記録する。フォントそのものは配布していない。ラベルは改行可能、省略不可。
