# 予約の確定と変更

## Intent

架空の共同作業室「みどり室」の予約を説明する。左から右へ、申請、確認待ち、確定の順に示す。

## Must show

- 申請 → 確認待ち → 確定の三段階を示す。
- 確認待ちは予約確定ではない。
- 確定した予約だけ「日時を変更」を使える。
- 変更申請は確認待ちに戻る。自動承認はない。

## May drop

- カレンダーの実日付、参加者の写真、料金。

## References

この説明はP00のために作成した架空の設定。外部資料・私有資料・第三者画像は使用していない。

## Lock

事実、状態、矢印の意味、下記ラベルを固定する。色は共通palette.jsonの意味役を使う。テスト用の描画であり、ユーザーによる選択・承認・プロジェクトスタイル固定ではない。

- `申請`
- `確認待ち`
- `確定`
- `日時を変更`

## Target

640 × 320 CSS pixels。配置はplacement.json。レイアウトの課題はhorizontal。最終サイズで確認する。

## Language and fonts

日本語。Noto Sans CJK JPを優先しsans-serifを予備とする。実際に使われたフォントと代替・欠落グリフの不確実性を記録する。フォントそのものは配布していない。ラベルは改行可能、省略不可。
