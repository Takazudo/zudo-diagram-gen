# 結果未到着の並行作業

## Intent

架空の展示会案内文を二人が並行に確認する。未到着を失敗と取り違えない説明にする。

## Must show

- 共通の案内文から「表記確認」と「会場情報確認」に分岐する。
- 表記確認は完了、会場情報確認は結果待ち。
- まとめ役は両方が完了するまで公開しない。
- 現時点で公開済みの案内はゼロ。

## May drop

- 人物名、具体的な待ち時間、公開システムの内部構造。

## References

この説明はP00のために作成した架空の設定。外部資料・私有資料・第三者画像は使用していない。

## Lock

事実、状態、矢印の意味、下記ラベルを固定する。色は共通palette.jsonの意味役を使う。テスト用の描画であり、ユーザーによる選択・承認・プロジェクトスタイル固定ではない。

- `案内文`
- `表記確認：完了`
- `会場情報確認：結果待ち`
- `両方完了後に公開`
- `公開済み：0`

## Target

720 × 240 CSS pixels。配置はplacement.json。レイアウトの課題はwide。最終サイズで確認する。

## Language and fonts

日本語。Noto Sans CJK JPを優先しsans-serifを予備とする。実際に使われたフォントと代替・欠落グリフの不確実性を記録する。フォントそのものは配布していない。ラベルは改行可能、省略不可。
