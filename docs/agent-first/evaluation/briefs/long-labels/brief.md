# 長いラベルの担当引継ぎ

## Intent

架空の資料作成チームで、長い日本語の担当名を省略せずに引継ぎ順を伝える。

## Must show

- 「地域交流イベント開催準備担当」から「参加申込内容の確認・連絡担当」へ資料を渡す。
- 確認担当が不足項目を見つけたら準備担当へ戻す。
- 不足がなければ「当日受付と案内の担当」へ渡す。
- 三つの担当名は省略せず、改行は許可する。

## May drop

- 役職アイコンの詳細、組織図、実在の会社名。

## References

この説明はP00のために作成した架空の設定。外部資料・私有資料・第三者画像は使用していない。

## Lock

事実、状態、矢印の意味、下記ラベルを固定する。色は共通palette.jsonの意味役を使う。テスト用の描画であり、ユーザーによる選択・承認・プロジェクトスタイル固定ではない。

- `地域交流イベント開催準備担当`
- `参加申込内容の確認・連絡担当`
- `当日受付と案内の担当`
- `不足項目あり`
- `確認完了`

## Target

480 × 360 CSS pixels。配置はplacement.json。レイアウトの課題はstacked。最終サイズで確認する。

## Language and fonts

日本語。Noto Sans CJK JPを優先しsans-serifを予備とする。実際に使われたフォントと代替・欠落グリフの不確実性を記録する。フォントそのものは配布していない。ラベルは改行可能、省略不可。
