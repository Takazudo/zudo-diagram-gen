---
title: Skills-only diagram workflow
description: A separate host-facing skill and onboarding path for bundled tone authoring.
---

The new host-facing `diagram-gen` skill guides a capable ChatGPT or Codex host to use the packaged tone catalog, author self-contained SVGs, render and actually inspect available previews, preserve selected saved baselines, and deliver exact saved files. It does not require the local engine, Node, pnpm, or browser workbench. The engine skill and existing CLI workflow remain available separately.

The [ChatGPT plugin guide](/docs/getting-started/chatgpt-plugin/) distinguishes the source folder from the assembled distributable, describes the documented local marketplace installation route, gives natural-language invocation and refinement examples, and labels account installation as unverified here. A host without file or image tools must report the reduced result and pending checks rather than claiming a downloadable or visually approved diagram.

The guide now includes the exact maintainer commands to build and verify a ZIP after extracting it outside the checkout. Local archive verification covers the complete tone catalog and inventory; it does not establish ChatGPT account installation or attachment behavior.
