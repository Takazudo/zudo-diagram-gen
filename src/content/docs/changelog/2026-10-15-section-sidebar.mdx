---
title: Keep sidebars within their section
sidebar_position: -20261015.2
---

Updated zudo-doc to 6.2.0 and the ZFB SDK, runtime and Markdown WebAssembly packages to 4.5.0. The formatter stays at 1.3.0. New local hosts use the same ZFB versions; the engine's existing ZFB 2, 3 and 4 compatibility range remains unchanged.

Sidebars now stop at the current section, matching the standard zudo-doc site. Getting Started and the other documentation sections no longer offer Broaden tree into unrelated sections. Pages, ordering, category links, filtering and the mobile drawer still use the framework's filesystem-generated navigation.

Removed the obsolete TypeScript baseUrl workaround and retained the native homepage, header, examples grid and saved diagrams.
