Released: 2026-09-27

### Changed

- The project site now uses [zudo-diagram-gen.zudolab.dev](https://zudo-diagram-gen.zudolab.dev/) as its production host. The previous `zudo-diagram-gen-doc.zudolab.dev` hostname has been retired.
- The Worked examples sidebar now lists only the category and its pages.
- The worked examples index uses an unboxed layout with zudo-doc tokens and follows the host's dark mode.
- The tone collection and embedded workbench now use zudo-doc tokens for a consistent look within the documentation site.
