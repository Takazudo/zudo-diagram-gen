Version 0.1.0 of the skills-only plugin is published as a [GitHub Release](https://github.com/Takazudo/zudo-diagram-gen/releases/tag/v0.1.0). It provides `zudo-diagram-gen-v0.1.0.zip`, an identical `zudo-diagram-gen.zip` for the stable [latest download](https://github.com/Takazudo/zudo-diagram-gen/releases/latest/download/zudo-diagram-gen.zip), and `SHA256SUMS`.

The ZIP contains the host-facing `diagram-gen` skill, its references and all 24 bundled tones. Each archive is validated after fresh extraction. That validation does not establish installation, discovery or the refinement flow in a ChatGPT account; see the [ChatGPT plugin workflow](/docs/getting-started/chatgpt-plugin/) for those boundaries.

No npm package is published, and the local engine and initializer archive versions are unchanged.
