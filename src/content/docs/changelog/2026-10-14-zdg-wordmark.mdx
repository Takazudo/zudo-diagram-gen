title: ZDG homepage logo
---

The homepage now uses the existing ZFB brand artwork with its lettering changed to ZDG. The original bird, fish, rectangular frame, and 1200 × 630 canvas are preserved; only the lettering is replaced with outlined, Futura-like geometric type, fitted to the existing text area.

The SVG has a transparent background and no runtime font dependency. The existing zudo-doc logo setting loads it as a theme-adaptive CSS mask. The favicon, navigation, and workbench are unchanged.
