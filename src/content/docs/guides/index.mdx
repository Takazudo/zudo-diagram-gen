## Take one drawing through review

- [Create a diagram manually](/docs/getting-started/manual-session/): a complete SVG and metadata walkthrough, also useful for understanding agent output.
- [Review candidates](/docs/gallery/reviewing/): compare at the actual placement size, choose a baseline and transfer feedback.
- [Refine and export the saved drawing](/docs/guides/refine-export/): carry the selected file into a new revision and deliver exact bytes.

## Keep related drawings consistent

- [Use multiple sessions in one project](/docs/authoring/projects/): register sessions, compare exact mappings and recover partial work.
- [Choose and apply a tone](/docs/authoring/tone-collection/): read the actual references and adapt them to your facts.
- [Lock and adopt a saved style](/docs/guides/saved-styles/): explicitly scope reuse and preserve immutable revisions.
- [Author readable SVGs](/docs/authoring/svg-authoring/): handle labels, themes, accessibility and placement.

## Work with a coding agent

- [Set up the core skill](/docs/agent-workflow/core-and-wrapper/): explicit file loading and optional verified discovery.
- [Coordinate generation and refinement](/docs/agent-workflow/iteration/): shared constraints, candidate ownership and saved baselines.
