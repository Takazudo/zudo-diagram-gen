---
title: Glossary
description: Shared terms for saved SVG work, review records and reusable style resources.
---

| Term | Meaning |
| --- | --- |
| Session | One brief, target size, set of rounds and stable session identity. |
| Round | An ordered group of candidates exploring or refining the same explanation. |
| Candidate | One saved drawing with a stable session-local ID, metadata and explicit theme assets. |
| Tone | An authored illustration treatment and its bundled examples and recipe; not a generated drawing or user selection. |
| Scheme | Versioned geometry, typography, palette-role and composition rules for a tone. |
| Kit | Reusable SVG primitives; authors can also draw ordinary hand geometry. |
| Placement | The intended CSS frame/slot, contain fit, theme and local resources used to judge a drawing. |
| Style revision | An immutable project snapshot of scheme, palette, kit, targets and explicit baseline selection. Later revisions require explicit adoption. |
| Review record | Notes, shortlist, chosen direction and fingerprints downloaded from browser state for explicit transfer. |
| Fingerprint | A content identity used to detect changed artwork/metadata; it is not approval. |

A **shortlist** keeps alternatives; a **chosen direction** identifies one drawing's baseline; **style adoption** authorizes a separately scoped reusable revision. A structural check, render, actual opened-image inspection and user approval are four separate results.
