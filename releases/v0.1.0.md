# zudo-diagram-gen v0.1.0

First versioned release of the skills-only ChatGPT plugin ZIP.

## Downloads

- `zudo-diagram-gen-v0.1.0.zip`: version-specific installable plugin.
- `zudo-diagram-gen.zip`: identical bytes under a stable name for the latest-release download URL.
- `SHA256SUMS`: SHA-256 checksums of both ZIP files.

GitHub's automatic **Source code** archives are not the installable plugin.

## Contents

- The host-facing `diagram-gen` skill, with references for tones, artifacts and review, and the optional local engine.
- The bundled catalog of all 24 drawing tones, with relative resources and an inventory hashed at build time.

The skill guides a capable host to author self-contained SVG diagrams in a chosen tone, inspect available previews, preserve a selected saved baseline when refining, and deliver the exact saved files. It does not require the local engine, Node, pnpm or the browser workbench.

## Verification

Download both ZIPs and `SHA256SUMS` into a fresh directory and run `shasum -a 256 -c SHA256SUMS` (macOS) or `sha256sum -c SHA256SUMS`. To check resources and inventory, extract the versioned ZIP and run `node scripts/plugin-pack.mjs --verify-dir <extracted>/zudo-diagram-gen` from a checkout.

## Limitations

- The archive was built and validated after fresh extraction. That does not establish ChatGPT account installation, native skill discovery, attachment/preview handling or the host refinement flow; [issue #100](https://github.com/Takazudo/zudo-diagram-gen/issues/100) tracks that acceptance.
- Native Mac/Safari verification ([issue #105](https://github.com/Takazudo/zudo-diagram-gen/issues/105)) remains separate.
- No npm package is published with this release; the local engine and initializer archives keep their own versions.
